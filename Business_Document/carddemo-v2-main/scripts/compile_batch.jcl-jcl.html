Summary

This JCL defines and executes a reusable procedure (BLDBAT) that compiles a COBOL source program named ZZZZZZZZ from the CardDemo application library, then prints the compilation listing, and finally link-edits the compiled output into an executable load module stored in the CardDemo load library. ### Key Functionalities: - Compiles the COBOL source member ZZZZZZZZ from the CardDemo COBOL source library (AWS.M2.CARDDEMO.CBL) using the IBM Enterprise COBOL compiler (IGYCRCTL), referencing copybook members from AWS.M2.CARDDEMO.CPY - Saves the compilation listing output to the CardDemo listing library (AWS.M2.CARDDEMO.LISTING) under member ZZZZZZZZ, then prints it to the system output using the IEBGENER utility - Link-edits the compiled object code into an executable load module and stores it as member ZZZZZZZZ in the CardDemo load library (AWS.M2.CARDDEMO.LOADLIB), resolving external references from system and runtime libraries

Step 1 - COMPILE.BLDBAT - Identify Source Program for Compilation

Business Rules

Supporting Code

Rule 1 — Identify Source Program: //SYSIN DD DISP=SHR, // DSN=AWS.M2.CARDDEMO.CBL(&MEM) Rule 2 — Resolve Copybook Definitions: //SYSLIB DD DISP=SHR, // DSN=AWS.M2.CARDDEMO.CPY Rule 3 — Apostrophe String Delimiter Standard: //COMPILE EXEC PGM=IGYCRCTL,REGION=0M, // PARM=(APOST,LIST,MAP,NUMBER) Rule 4 — Full Source Listing with Line Numbers: //COMPILE EXEC PGM=IGYCRCTL,REGION=0M, // PARM=(APOST,LIST,MAP,NUMBER) Rule 5 — Generate Data Structure Map: //COMPILE EXEC PGM=IGYCRCTL,REGION=0M, // PARM=(APOST,LIST,MAP,NUMBER) Rule 6 — Archive Permanent Compilation Listing: //SYSPRINT DD DISP=SHR, // DSN=AWS.M2.CARDDEMO.LISTING(&MEM) Rule 7 — Produce Compiled Object Module for Linking: //SYSLIN DD DSN=&&LOADSET,UNIT=3390, // DISP=(MOD,PASS),SPACE=(80,(10,10))

Business Rules

Supporting Code

Step 3 - STEP1.BLDBAT - Deploy Compiled Program to CardDemo Application Library

Business Rules

Supporting Code

**Rule 1 — Deploy Compiled Program to CardDemo Application Library:** ``` //LKED EXEC PGM=HEWL,REGION=0M,PARM='LIST,XREF' //SYSLIN DD DSN=&&LOADSET,DISP=(OLD,DELETE) //SYSLMOD DD DISP=SHR, // DSN=AWS.M2.CARDDEMO.LOADLIB(&MEM) //SYSPRINT DD SYSOUT=* ``` **Rule 2 — Enforce Library Resolution Search Order:** ``` //SYSLIB DD DSN=SYS1.LINKLIB,DISP=SHR ← 1st: IBM System Routines // DD DSN=CSF.SCSFMOD0,DISP=SHR ← 2nd: Cryptographic Services // DD DSN=CEE.SCEELKED,DISP=SHR ← 3rd: Language Environment Runtime // DD DSN=CEE.SCEELKEX,DISP=SHR ← 4th: Language Environment Extended // DD DSN=AWS.M2.CARDDEMO.LOADLIB,DISP=SHR ← 5th: CardDemo Application Modules ``` **Rule 3 — Enforce Cryptographic Services Dependency:** ``` //SYSLIB DD DSN=SYS1.LINKLIB,DISP=SHR // DD DSN=CSF.SCSFMOD0,DISP=SHR ← Mandatory Cryptographic Services // DD DSN=CEE.SCEELKED,DISP=SHR // DD DSN=CEE.SCEELKEX,DISP=SHR // DD DSN=AWS.M2.CARDDEMO.LOADLIB,DISP=SHR ``` **Rule 4 — Enforce Single-Use and Automatic Cleanup of Compiled Object Module:** ``` //SYSLIN DD DSN=&&LOADSET,DISP=(OLD,DELETE) ← OLD=exclusive access, DELETE=auto cleanup ``` **Rule 5 — Maintain Member Name Consistency Between Source and Executable:** ``` //SYSIN DD DISP=SHR, // DSN=AWS.M2.CARDDEMO.CBL(&MEM) ← Source uses &MEM //SYSPRINT DD DISP=SHR, // DSN=AWS.M2.CARDDEMO.LISTING(&MEM) ← Listing uses &MEM //SYSLMOD DD DISP=SHR, // DSN=AWS.M2.CARDDEMO.LOADLIB(&MEM) ← Executable uses same &MEM ``` **Rule 6 — Enable Inter-Program Calls Within CardDemo Application:** ``` //SYSLIB DD DSN=SYS1.LINKLIB,DISP=SHR // DD DSN=CSF.SCSFMOD0,DISP=SHR // DD DSN=CEE.SCEELKED,DISP=SHR // DD DSN=CEE.SCEELKEX,DISP=SHR // DD DSN=AWS.M2.CARDDEMO.LOADLIB,DISP=SHR ← CardDemo inter-program resolution //SYSLMOD DD DISP=SHR, // DSN=AWS.M2.CARDDEMO.LOADLIB(&MEM) ```
