Summary

COBSWAIT is a batch utility program within the CardDemo application that introduces a controlled pause/wait in program execution. It accepts a wait duration value (in centiseconds) from SYSIN input and delegates the actual wait operation to an external routine called MVSWAIT. This program is typically used to introduce deliberate delays between batch processing steps.
- **Execution Environment**: Batch - **Database Access**: None - **MQ Calls**: No - **Module Type**: Main/Driver module
### Key Functionalities: 1: Accept Wait Duration - Read the wait duration value (in centiseconds) from the system input (SYSIN) 2: Convert Wait Parameter - Move the accepted input parameter value into the numeric wait time field for processing 3: Execute Wait - Invoke the wait utility with the specified duration to pause program execution for the given number of centiseconds 4: Terminate Program - Stop the program execution after the wait period has completed
