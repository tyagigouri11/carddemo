Summary

This JCL job converts a text-based card statement file into a PDF document. It executes the TXT2PDF utility to read an input sequential file containing card demo statements and produces a PDF output file, enabling business users to view and distribute statements in a portable document format. ### Key Functionalities: - Reads the input card statement file (AWS.M2.CARDDEMO.STATEMNT.PS) in browse mode to convert its text content into PDF format. - Generates a PDF output file named AWS.M2.CARDDEMO.STATEMNT.PS.PDF containing the converted statement data. - Utilizes the TXT2PDF rexx/exec utility loaded from dedicated libraries (AWS.M2.LBD.TXT2PDF.LOAD and AWS.M2.LBD.TXT2PDF.EXEC) to perform the text-to-PDF conversion.

**Conditional Execution Rule (Step is skipped if any prior step failed):** ```jcl //TXT2PDF EXEC PGM=IKJEFT1B,DYNAMNBR=50, // COND=(0,NE) ``` **Input Source — Plain-text Customer Account Statement (Read-Only):** ```jcl //INDD DD DISP=SHR,DSN=AWS.M2.CARDDEMO.STATEMNT.PS ``` **Conversion Command — Browse Mode, Input, and Output PDF Destination:** ```jcl //SYSTSIN DD * %TXT2PDF BROWSE Y IN DD:INDD + OUT 'AWS.M2.CARDDEMO.STATEMNT.PS.PDF' /* ```
