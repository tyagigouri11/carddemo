Summary

This JCL job initializes and rebuilds the Transaction Master VSAM file structure for the CardDemo application. It deletes existing VSAM files, recreates the primary keyed cluster and alternate index, loads initial transaction data, and reopens the files for online CICS processing. ### Key Functionalities: - Closes the Transaction (TRANSACT) and Alternate Index (CXACAIX) CICS files before any structural changes to prevent data corruption during the rebuild process. - Deletes the existing Transaction VSAM KSDS cluster (AWS.M2.CARDDEMO.TRANSACT.VSAM.KSDS) and its Alternate Index (AWS.M2.CARDDEMO.TRANSACT.VSAM.AIX), suppressing warnings for conditions up to return code 8 (e.g., file not found). - Recreates the Transaction VSAM KSDS cluster with a primary key of 16 bytes starting at offset 0, fixed record size of 350 bytes, allocated 1 primary cylinder with 5 secondary cylinders on volume AWSHJ1, with share options (2,3). - Loads initial transaction data from the sequential seed file (AWS.M2.CARDDEMO.DALYTRAN.PS.INIT) into the newly created VSAM KSDS cluster. - Defines a new Alternate Index (AWS.M2.CARDDEMO.TRANSACT.VSAM.AIX) on the KSDS with a non-unique key of 26 bytes at offset 304, allocated 5 primary cylinders with 1 secondary cylinder, set to automatically upgrade when the base cluster is updated. - Creates an Access Path (AWS.M2.CARDDEMO.TRANSACT.VSAM.AIX.PATH) for the Alternate Index to enable access to the KSDS via the alternate key. - Builds the Alternate Index entries by scanning the base KSDS cluster and populating the AIX dataset. - Reopens the TRANSACT and CXACAIX CICS files to restore online transaction processing availability after the rebuild is complete.

Dataset Information (4)

Dataset/Table Name Type Usage
AWS.M2.CARDDEMO.TRANSACT.VSAM.KSDS VSAM_KSDS Deleted and recreated as the primary Transaction Master cluster. Primary key is 16 bytes at offset 0, fixed record size of 350 bytes, allocated on volume AWSHJ1. Subsequently used as output target for initial data load and as the base cluster for the alternate index build.
AWS.M2.CARDDEMO.TRANSACT.VSAM.AIX VSAM_KSDS Deleted and recreated as an Alternate Index on the Transaction KSDS. Non-unique key of 26 bytes at offset 304, fixed record size of 350 bytes, allocated on volume AWSHJ1. Populated via BLDINDEX from the base KSDS cluster. Set to UPGRADE automatically.
AWS.M2.CARDDEMO.TRANSACT.VSAM.AIX.PATH VSAM_KSDS Defined as an access path entry pointing to the Alternate Index (AWS.M2.CARDDEMO.TRANSACT.VSAM.AIX) to allow access to the base KSDS via the alternate key.
AWS.M2.CARDDEMO.DALYTRAN.PS.INIT SEQUENTIAL Input seed file containing initial transaction records. Read with shared disposition and reproduced into the Transaction VSAM KSDS cluster during the data load step.

Step 1 - CLCIFIL - Close CICS Transaction Primary File Before Batch Rebuild

Business Rules

Supporting Code

/* Business Rule 1 — Close CICS Transaction Primary File */ /F CICSAWSA,'CEMT SET FIL(TRANSACT ) CLO' /* Business Rule 2 — Close CICS Card Number Alternate Index File */ /F CICSAWSA,'CEMT SET FIL(CXACAIX ) CLO'

Step 2 - STEP05 - Delete Existing Transaction Primary Dataset Before Rebuild

Business Rules

Supporting Code

DELETE AWS.M2.CARDDEMO.TRANSACT.VSAM.KSDS - CLUSTER IF MAXCC LE 08 THEN SET MAXCC = 0 DELETE AWS.M2.CARDDEMO.TRANSACT.VSAM.AIX - ALTERNATEINDEX IF MAXCC LE 08 THEN SET MAXCC = 0

Step 5 - STEP20 - Define Card Number Alternate Index Over Transaction Master Dataset

Business Rules

Supporting Code

Rule 1 — Alternate Index definition and relationship to Transaction Primary Dataset: ``` DEFINE ALTERNATEINDEX (NAME(AWS.M2.CARDDEMO.TRANSACT.VSAM.AIX)- RELATE(AWS.M2.CARDDEMO.TRANSACT.VSAM.KSDS) ``` Rule 2 — Card Number as secondary key (position and length): ``` KEYS(26 304) ``` Rule 3 — Non-unique key policy (one card → many transactions): ``` NONUNIQUEKEY ``` Rule 4 — Automatic index synchronization on base dataset changes: ``` UPGRADE ``` Rule 5 — Fixed record size enforcement: ``` RECORDSIZE(350,350) ``` Rule 6 — Storage allocation on designated volume: ``` VOLUMES(AWSHJ1) - CYLINDERS(5,1) ``` Rule 7 — Named data and index components: ``` DATA (NAME(AWS.M2.CARDDEMO.TRANSACT.VSAM.AIX.DATA)) - INDEX (NAME(AWS.M2.CARDDEMO.TRANSACT.VSAM.AIX.INDEX)) ```
