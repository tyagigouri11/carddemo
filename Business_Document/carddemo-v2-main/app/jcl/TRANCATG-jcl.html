Summary

This JCL job sets up the Transaction Category reference data store for the CardDemo application. It recreates the Transaction Category VSAM indexed file from scratch by deleting any existing version, defining a new structured file, and loading it with current transaction category data from a sequential source file. ### Key Functionalities: - Deletes the existing Transaction Category VSAM indexed file (AWS.M2.CARDDEMO.TRANCATG.VSAM.KSDS) to ensure a clean setup, suppressing any errors if the file does not exist. - Creates a new Transaction Category VSAM indexed file with a fixed record size of 60 bytes, a 6-byte key starting at position 0, allocated on volume AWSHJ1 with 1 primary and 5 secondary cylinders, configured for indexed access with erase-on-delete and controlled sharing. - Loads the newly created Transaction Category VSAM file with transaction category records sourced from the sequential flat file (AWS.M2.CARDDEMO.TRANCATG.PS), making the reference data available for the CardDemo application.

Step 2 - STEP10 - Define Transaction Category Master File Identity

Business Rules

Supporting Code

Rule 1 – Transaction Category Master File Identity: ``` DEFINE CLUSTER (NAME(AWS.M2.CARDDEMO.TRANCATG.VSAM.KSDS) - INDEXED - ) ``` Rule 2 – Transaction Category Code as Unique Key: ``` KEYS(6 0) ``` Rule 3 – Fixed 60-Character Record Size: ``` RECORDSIZE(60 60) ``` Rule 4 – Physical Erasure on Deletion: ``` ERASE ``` Rule 5 – Concurrent Access Control: ``` SHAREOPTIONS(2 3) ``` Rule 6 – Designated Storage Volume: ``` VOLUMES(AWSHJ1) ``` Rule 7 – Storage Capacity Allocation: ``` CYLINDERS(1 5) ``` Rule 8 – Separate Data and Index Components: ``` DATA (NAME(AWS.M2.CARDDEMO.TRANCATG.VSAM.KSDS.DATA) - ) INDEX (NAME(AWS.M2.CARDDEMO.TRANCATG.VSAM.KSDS.INDEX) - ) ```
