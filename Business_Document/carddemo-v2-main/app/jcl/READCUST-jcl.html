Summary

The JCL job **READCUST** executes program **CBCUS01C** to read customer data from a VSAM Key-Sequenced Dataset (KSDS). The job accesses the customer master file in shared mode, processes customer records, and directs all output messages to the system output. This is a read-only operation against the customer data store with no updates or writes performed. ### Key Functionalities: - Reads customer records from the AWS CardDemo customer VSAM KSDS file (AWS.M2.CARDDEMO.CUSTDATA.VSAM.KSDS) in shared (read-only) mode - Processes customer data through program CBCUS01C loaded from the CardDemo application load library - Directs all program output and print messages to the system output for reporting or logging purposes
