Summary

This JCL job manages the complete rebuild of the Card Data VSAM file structure used by the CardDemo application. It closes the CICS-managed card data files, deletes and recreates the primary VSAM cluster and alternate index, loads card data from a flat file source, builds the alternate index, and reopens the files for CICS use. ### Key Functionalities: - Closes the CICS-managed card data files (CARDDAT and CARDAIX) in the CICSAWSA region to allow exclusive access for file restructuring operations. - Deletes the existing primary VSAM Key-Sequenced Data Set (AWS.M2.CARDDEMO.CARDDATA.VSAM.KSDS) and its associated Alternate Index (AWS.M2.CARDDEMO.CARDDATA.VSAM.AIX), suppressing warnings for return codes up to 8. - Recreates the primary VSAM KSDS cluster (AWS.M2.CARDDEMO.CARDDATA.VSAM.KSDS) with a 16-byte key starting at position 0, fixed record size of 150 bytes, allocated on volume AWSHJ1 with 1 primary and 5 secondary cylinders. - Loads card data records from the sequential flat file (AWS.M2.CARDDEMO.CARDDATA.PS) into the newly created VSAM KSDS cluster. - Defines a new Alternate Index (AWS.M2.CARDDEMO.CARDDATA.VSAM.AIX) related to the primary KSDS, using an 11-byte key at position 16, configured as non-unique to support multiple cards per customer, with automatic upgrade enabled. - Creates an Access Path (AWS.M2.CARDDEMO.CARDDATA.VSAM.AIX.PATH) to enable access to the KSDS through the Alternate Index. - Builds the Alternate Index entries by reading the primary KSDS and populating the AIX dataset. - Reopens both CICS-managed card data files (CARDDAT and CARDAIX) in the CICSAWSA region to resume normal online transaction processing.

Dataset/Table Name Type Usage
AWS.M2.CARDDEMO.CARDDATA.VSAM.KSDS VSAM_KSDS Deleted and recreated as primary card data cluster. Fixed record size of 150 bytes, 16-byte key at position 0, allocated on volume AWSHJ1. Used as output target for data load from flat file and as input source for building the alternate index.
AWS.M2.CARDDEMO.CARDDATA.VSAM.KSDS.DATA VSAM_KSDS Data component of the primary KSDS cluster, defined as part of the VSAM cluster creation in STEP10.
AWS.M2.CARDDEMO.CARDDATA.VSAM.KSDS.INDEX VSAM_KSDS Index component of the primary KSDS cluster, defined as part of the VSAM cluster creation in STEP10.
AWS.M2.CARDDEMO.CARDDATA.VSAM.AIX VSAM_KSDS Alternate index over the primary KSDS, deleted and recreated. Uses an 11-byte non-unique key at position 16 with automatic upgrade enabled. Output target during alternate index build in STEP60.
AWS.M2.CARDDEMO.CARDDATA.VSAM.AIX.DATA VSAM_KSDS Data component of the alternate index, defined as part of the alternate index creation in STEP40.
AWS.M2.CARDDEMO.CARDDATA.VSAM.AIX.INDEX VSAM_KSDS Index component of the alternate index, defined as part of the alternate index creation in STEP40.
AWS.M2.CARDDEMO.CARDDATA.VSAM.AIX.PATH VSAM_KSDS Access path defined in STEP50 to enable navigation from the alternate index to the primary KSDS. Created as a new path entry pointing to the alternate index.
AWS.M2.CARDDEMO.CARDDATA.PS SEQUENTIAL Input flat file containing card data records used to populate the VSAM KSDS in STEP15. Opened with shared disposition.

Step 1 - CLCIFIL - Close CICS Primary Card Data File Before Batch Processing

Business Rules

Supporting Code

Rule 1 — Close CICS Primary Card Data File (CARDDAT): /F CICSAWSA,'CEMT SET FIL(CARDDAT ) CLO' Rule 2 — Close CICS Card Data Alternate Index File (CARDAIX): /F CICSAWSA,'CEMT SET FIL(CARDAIX ) CLO'

Business Rules

Supporting Code

| Rule | Supporting JCL Code | |------|-------------------| | Delete Existing Card Data Primary VSAM File | `DELETE AWS.M2.CARDDEMO.CARDDATA.VSAM.KSDS - CLUSTER` | | Tolerate Missing Card Data Primary VSAM File During Deletion | `IF MAXCC LE 08 THEN SET MAXCC = 0` *(first occurrence — immediately after DELETE KSDS)* | | Delete Existing Card Data Alternate Index | `DELETE AWS.M2.CARDDEMO.CARDDATA.VSAM.AIX - ALTERNATEINDEX` | | Tolerate Missing Card Data Alternate Index During Deletion | `IF MAXCC LE 08 THEN SET MAXCC = 0` *(second occurrence — immediately after DELETE AIX)* |
