Summary

This JCL job (CBADMCDJ) configures the CICS environment for the CardDemo application by defining all necessary CICS resources — including a program library, map sets, programs, and transactions — into a CICS System Definition (CSD) group named CARDDEMO. It uses the CICS utility DFHCSDUP to register all CardDemo application components so they can be installed and executed within the CICS region. ### Key Functionalities: - Defines a CICS library resource (COM2DOLL) pointing to the CardDemo load library (AWS.M2.CARDDEMO.LOADLIB), which contains all compiled application programs. - Registers 18 CICS map sets covering all application screens: Login, Account Menu, View/Update/Deactivate Account, Card Menu, View/Update/Deactivate Card, Transaction, Transaction Report, Transaction Details, Add Transactions, Bill Pay Setup, Admin Menu, and four test program screens (PGM1–PGM4). - Registers 18 CICS programs covering all application functions: Login (COSGN00C), Account management (COACT00C, COACTVWC, COACTUPC, COACTDEC), Card management, Transaction processing (COTRN00C, COTRNVWC, COTRNVDC, COTRNATC), Bill Pay (COBIL00C), Admin Menu (COADM00C), and four test programs (COTSTP1C–COTSTP4C). - Defines CICS transactions linking programs to transaction IDs: CC00 (Login), CCAD (Admin Menu), CCDM (Admin Menu via COADM00C), CCT1–CCT4 (Test Programs 1–4). - Generates a listing of all defined resources in the CARDDEMO group to confirm successful registration. - Note: The DELETE GROUP(CARDDEMO) command is commented out, meaning existing definitions will not be removed before re-running; this must be manually uncommented if re-execution is needed.

Dataset Information (3)

Dataset/Table Name Type Usage
OEM.CICSTS.DFHCSD VSAM_KSDS Input/Output — The CICS System Definition (CSD) file opened in READ/WRITE mode. All CARDDEMO resource definitions (library, map sets, programs, transactions) are written into this file during job execution. Shared disposition allows concurrent access.
OEM.CICSTS.V05R06M0.CICS.SDFHLOAD PDS Input — CICS load library providing the DFHCSDUP utility program required to execute the CSD update step. Accessed in shared read-only mode.
AWS.M2.CARDDEMO.LOADLIB PDS Input — CardDemo application load library referenced in the CICS library definition (COM2DOLL). This library contains all compiled CardDemo CICS programs that will be made available to the CICS region after installation of the CARDDEMO group.
