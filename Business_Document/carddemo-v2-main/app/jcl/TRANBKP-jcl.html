Summary

This JCL job (TRANBKP) performs a three-phase backup and refresh cycle for the Credit Card Transaction Master VSAM it first copies all transaction records to a versioned backup, then deletes the existing VSAM cluster and its alternate index, and finally recreates a fresh empty VSAM cluster ready for new transactions. ### Key Functionalities: - Backs up the Transaction Master VSAM file (AWS.M2.CARDDEMO.TRANSACT.VSAM.KSDS) by copying all 350-byte fixed-length transaction records into a new generation of the backup GDG dataset (AWS.M2.CARDDEMO.TRANSACT.BKUP(+1)), preserving a versioned history of transactions. - Deletes the existing Transaction Master VSAM cluster (AWS.M2.CARDDEMO.TRANSACT.VSAM.KSDS) and its associated Alternate Index (AWS.M2.CARDDEMO.TRANSACT.VSAM.AIX), suppressing non-critical errors (return codes up to 8) to ensure a clean removal. - Recreates the Transaction Master VSAM KSDS cluster from scratch with a 16-byte key starting at position 0, fixed record size of 350 bytes, allocated on volume AWSHJ1 with 1 primary and 5 secondary cylinders, and share options (2,3), making it ready to accept new transaction data.

Dataset Information (5)

Dataset/Table Name Type Usage
AWS.M2.CARDDEMO.TRANSACT.VSAM.KSDS VSAM_KSDS Input source for backup operation (shared read access). Subsequently deleted in STEP05 as part of the refresh cycle. Recreated as an empty cluster in STEP10 with 350-byte fixed records, 16-byte key at offset 0, 1 primary and 5 secondary cylinders on volume AWSHJ1, share options (2,3).
AWS.M2.CARDDEMO.TRANSACT.BKUP GDG Output backup destination. A new generation (+1) is created and cataloged during the backup step. Stores fixed-length 350-byte transaction records copied from the Transaction Master VSAM file. Allocated on SYSDA with 1 primary and 1 secondary cylinder; released unused space upon close.
AWS.M2.CARDDEMO.TRANSACT.VSAM.KSDS.DATA VSAM_KSDS Data component of the Transaction Master VSAM cluster. Implicitly deleted in STEP05 as part of the cluster deletion and explicitly defined as a named data component when the cluster is recreated in STEP10.
AWS.M2.CARDDEMO.TRANSACT.VSAM.KSDS.INDEX VSAM_KSDS Index component of the Transaction Master VSAM cluster. Implicitly deleted in STEP05 as part of the cluster deletion and explicitly defined as a named index component when the cluster is recreated in STEP10.
AWS.M2.CARDDEMO.TRANSACT.VSAM.AIX VSAM_KSDS Alternate Index associated with the Transaction Master VSAM cluster. Deleted in STEP05 as part of the cleanup process; non-critical errors (return codes up to 8) are suppressed during deletion.

Step 1 - PRC001 - Full Card Transaction Data Backup

Business Rules

Supporting Code

**Rule 1 — Full Card Transaction Data Backup:** ```jcl //SYSIN DD * REPRO INFILE(FILEIN) OUTFILE(FILEOUT) ``` **Rule 2 — Versioned Backup Generation:** ```jcl //FILEOUT DD DISP=(NEW,CATLG,DELETE), // DSN=AWS.M2.CARDDEMO.TRANSACT.BKUP(+1) ``` **Rule 3 — Backup Integrity Protection on Failure:** ```jcl //FILEOUT DD DISP=(NEW,CATLG,DELETE), ``` *(NEW = create new; CATLG = catalog if success; DELETE = discard if failure)* **Rule 4 — Card Transaction Backup Record Format Consistency:** ```jcl //FILEOUT DD DISP=(NEW,CATLG,DELETE), // DCB=(LRECL=350,RECFM=FB,BLKSIZE=0), ``` **Rule 5 — Non-Blocking Concurrent Access During Backup:** ```jcl //FILEIN DD DISP=SHR, // DSN=AWS.M2.CARDDEMO.TRANSACT.VSAM.KSDS ``` **Rule 6 — Automatic Release of Unused Backup Storage:** ```jcl // SPACE=(CYL,(1,1),RLSE), ```

Step 2 - STEP05 - Delete Card Transaction VSAM Cluster

Business Rules

Supporting Code

Rule 1 — Delete Card Transaction VSAM Cluster: ``` DELETE AWS.M2.CARDDEMO.TRANSACT.VSAM.KSDS - CLUSTER ``` Rule 2 — Tolerate Absent VSAM Cluster (RC ≤ 8 reset to 0): ``` DELETE AWS.M2.CARDDEMO.TRANSACT.VSAM.KSDS - CLUSTER IF MAXCC LE 08 THEN SET MAXCC = 0 ``` Rule 3 — Delete Card Transaction Alternate Index: ``` DELETE AWS.M2.CARDDEMO.TRANSACT.VSAM.AIX - ALTERNATEINDEX ``` Rule 4 — Tolerate Absent Alternate Index (RC ≤ 8 reset to 0): ``` DELETE AWS.M2.CARDDEMO.TRANSACT.VSAM.AIX - ALTERNATEINDEX IF MAXCC LE 08 THEN SET MAXCC = 0 ```
