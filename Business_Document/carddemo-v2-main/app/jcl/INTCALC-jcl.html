Summary

The JCL job **INTCALC** executes program **CBACT04C** to calculate interest charges for credit card accounts as of the processing date **July 18, 2022** (passed as parameter `2022071800`). It reads transaction category balances, account cross-reference data, account details, and discount group definitions to compute interest, then writes the resulting interest transaction records to a new generation of a Generation Data Group (GDG) output file. ### Key Functionalities: - Reads transaction category balance data (TCATBALF) to identify per-category balances on which interest is to be calculated for each account. - Looks up card-to-account cross-reference information (XREFFILE and XREFFIL1) using both the primary KSDS path and the alternate index path to resolve card numbers to account numbers. - Retrieves account master data (ACCTFILE) to obtain account-level details such as credit limits, current balances, and account status needed for interest computation. - References discount group definitions (DISCGRP) to determine the applicable interest rates and discount rules for each account's transaction categories. - Generates a new sequential output file as the next generation (GDG +1) of **AWS.M2.CARDDEMO.SYSTRAN**, writing fixed-length 350-byte interest transaction records; the file is catalogued on success and deleted on failure.

Supporting Code

```jcl //STEP15 EXEC PGM=CBACT04C,PARM='2022071800' ``` → Triggers the Interest Calculator program for processing date July 18, 2022, Cycle 00 ```jcl //TCATBALF DD DISP=SHR, // DSN=AWS.M2.CARDDEMO.TCATBALF.VSAM.KSDS ``` → Transaction Category Balance File — provides category-level balance summaries for interest computation ```jcl //XREFFILE DD DISP=SHR, // DSN=AWS.M2.CARDDEMO.CARDXREF.VSAM.KSDS //XREFFIL1 DD DISP=SHR, // DSN=AWS.M2.CARDDEMO.CARDXREF.VSAM.AIX.PATH ``` → Card Cross-Reference File (primary + alternate index) — resolves card numbers to account numbers ```jcl //ACCTFILE DD DISP=SHR, // DSN=AWS.M2.CARDDEMO.ACCTDATA.VSAM.KSDS ``` → Account Data File — provides account balances, credit limits, and account status ```jcl //DISCGRP DD DISP=SHR, // DSN=AWS.M2.CARDDEMO.DISCGRP.VSAM.KSDS ``` → Disclosure Group File — provides applicable interest rates and fee structures per account group ```jcl //TRANSACT DD DISP=(NEW,CATLG,DELETE), // DCB=(RECFM=F,LRECL=350,BLKSIZE=0), // DSN=AWS.M2.CARDDEMO.SYSTRAN(+1) ``` → Output: New generation of System Transaction File with fixed 350-character records; CATLG = catalog on success; DELETE = discard on failure
