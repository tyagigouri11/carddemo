Summary

The JCL job READACCT reads account data from a VSAM KSDS file and extracts/transforms the records into three different sequential output files: a compressed fixed-block file, an array-based fixed-block file, and a variable-block file. The job first cleans up any pre-existing output files before executing the main account data extraction program CBACT01C. ### Key Functionalities: - Deletes any pre-existing versions of three output datasets (PSCOMP, ARRYPS, VBPS) before processing to ensure clean output files - Reads account data from the VSAM KSDS source file (AWS.M2.CARDDEMO.ACCTDATA.VSAM.KSDS) containing customer account records - Writes account records to a compressed sequential fixed-block output file (PSCOMP) with a record length of 107 bytes - Writes account records to an array-format sequential fixed-block output file (ARRYPS) with a record length of 110 bytes - Writes account records to a variable-block sequential output file (VBPS) with a maximum record length of 84 bytes - All three output files are newly created, cataloged, and allocated with 1 primary cylinder and 2 secondary cylinders of disk space

Step 1 - PREDEL - Pre-Processing Cleanup of Account Data Output Files

Business Rules

Supporting Code

**Rule 1 — Pre-Processing Cleanup of Account Data Output Files:** ```jcl //PREDEL EXEC PGM=IEFBR14 //DD01 DD DSN=AWS.M2.CARDDEMO.ACCTDATA.PSCOMP, // DISP=(MOD,DELETE,DELETE) //DD02 DD DSN=AWS.M2.CARDDEMO.ACCTDATA.ARRYPS, // DISP=(MOD,DELETE,DELETE) //DD03 DD DSN=AWS.M2.CARDDEMO.ACCTDATA.VBPS, // DISP=(MOD,DELETE,DELETE) ``` > All three DD statements with `DISP=(MOD,DELETE,DELETE)` confirm that PSCOMP, ARRYPS, and VBPS are targeted for deletion at the start of every job run. --- **Rule 2 — Unconditional Deletion on Any Step Outcome:** ```jcl //DD01 DD DSN=AWS.M2.CARDDEMO.ACCTDATA.PSCOMP, // DISP=(MOD,DELETE,DELETE) ← DELETE(normal), DELETE(abnormal) //DD02 DD DSN=AWS.M2.CARDDEMO.ACCTDATA.ARRYPS, // DISP=(MOD,DELETE,DELETE) ← DELETE(normal), DELETE(abnormal) //DD03 DD DSN=AWS.M2.CARDDEMO.ACCTDATA.VBPS, // DISP=(MOD,DELETE,DELETE) ← DELETE(normal), DELETE(abnormal) ``` > The second parameter `DELETE` (normal completion) and third parameter `DELETE` (abnormal completion) in `DISP=(MOD,DELETE,DELETE)` enforce deletion on **both** success and failure paths for all three files. --- **Rule 3 — Graceful Handling When Files Do Not Exist:** ```jcl //DD01 DD DSN=AWS.M2.CARDDEMO.ACCTDATA.PSCOMP, // DISP=(MOD,DELETE,DELETE) ← MOD: no error if file does not exist //DD02 DD DSN=AWS.M2.CARDDEMO.ACCTDATA.ARRYPS, // DISP=(MOD,DELETE,DELETE) ← MOD: no error if file does not exist //DD03 DD DSN=AWS.M2.CARDDEMO.ACCTDATA.VBPS, // DISP=(MOD,DELETE,DELETE) ← MOD: no error if file does not exist ``` > The first parameter `MOD` in `DISP=(MOD,DELETE,DELETE)` instructs the system to open the file if it exists or silently create a temporary placeholder if it does not — preventing any job failure when files are absent.

Step 2 - STEP05 - Account Data Extraction and Multi-Format Output Generation

Business Rules

Supporting Code

```jcl /* Calls the external Account Data Extraction program */ //STEP05 EXEC PGM=CBACT01C /* Master Account Database — shared read access (no exclusive lock) */ //ACCTFILE DD DISP=SHR, // DSN=AWS.M2.CARDDEMO.ACCTDATA.VSAM.KSDS /* Output 1: Compressed Fixed-Length Account Data File (107-byte records) */ /* CATLG on success / DELETE on failure */ //OUTFILE DD DSN=AWS.M2.CARDDEMO.ACCTDATA.PSCOMP, // DISP=(NEW,CATLG,DELETE), // DCB=(LRECL=107,RECFM=FB,DSORG=PS,BLKSIZE=0) /* Output 2: Array-Structured Fixed-Length Account Data File (110-byte records) */ /* CATLG on success / DELETE on failure */ //ARRYFILE DD DSN=AWS.M2.CARDDEMO.ACCTDATA.ARRYPS, // DISP=(NEW,CATLG,DELETE), // DCB=(LRECL=110,RECFM=FB,DSORG=PS,BLKSIZE=0) /* Output 3: Variable-Block Account Data File (up to 84-byte records) */ /* CATLG on success / DELETE on failure */ //VBRCFILE DD DSN=AWS.M2.CARDDEMO.ACCTDATA.VBPS, // DISP=(NEW,CATLG,DELETE), // DCB=(LRECL=84,RECFM=VB,DSORG=PS,BLKSIZE=0) /* Operational logging for audit and monitoring */ //SYSOUT DD SYSOUT=* //SYSPRINT DD SYSOUT=* ```
