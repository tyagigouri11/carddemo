Summary

This JCL job (PRTCATBL) extracts transaction category balance data from a VSAM file, creates a backup copy, and produces a formatted, sorted report file. The report presents transaction category balances sorted by Account ID, Transaction Type Code, and Transaction Category Code, with balances formatted to two decimal places. ### Key Functionalities: - Deletes any pre-existing version of the report output file (AWS.M2.CARDDEMO.TCATBALF.REPT) before processing begins, ensuring a clean run. - Unloads/copies the Transaction Category Balance VSAM KSDS file (AWS.M2.CARDDEMO.TCATBALF.VSAM.KSDS) into a new Generation Data Group (GDG) backup dataset with fixed-block records of 50 bytes each. - Sorts the backup data in ascending order by Account ID (positions 1-11), Transaction Type Code (positions 12-2), and Transaction Category Code (positions 14-4). - Formats the output report records (40 bytes, fixed-block) by arranging Account ID, Transaction Type Code, Transaction Category Code, and Transaction Category Balance (formatted as a numeric value with 2 decimal places, e.g., TTTTTTTTT.TT) separated by spaces, and saves the result as the final report file (AWS.M2.CARDDEMO.TCATBALF.REPT).

Dataset/Table Name Type Usage

AWS.M2.CARDDEMO.TCATBALF.BKUP(+1) GDG Output - Newly created and cataloged generation dataset used as backup of the VSAM file; fixed-block records of 50 bytes; allocated 1 cylinder with 1 cylinder extension; also used as input to the subsequent sort step

Step 1 - DELDEF - Delete Existing Transaction Category Balance Report Before Regeneration

Business Rules

Supporting Code

//DELDEF EXEC PGM=IEFBR14 //THEFILE DD DISP=(MOD,DELETE), // UNIT=SYSDA, // SPACE=(TRK,(1,1),RLSE), // DSN=AWS.M2.CARDDEMO.TCATBALF.REPT

Step 2 - PRC001 - Full Backup of Transaction Category Balance File

Business Rules

Supporting Code

//PRC001 EXEC PGM=IDCAMS // — Executes the IDCAMS utility to perform the backup operation //FILEIN DD DISP=SHR, // DSN=AWS.M2.CARDDEMO.TCATBALF.VSAM.KSDS // — Source: Transaction Category Balance VSAM master file opened in read-only shared mode //FILEOUT DD DISP=(NEW,CATLG,DELETE), // DCB=(LRECL=50,RECFM=FB,BLKSIZE=0), // DSN=AWS.M2.CARDDEMO.TCATBALF.BKUP(+1) // — Destination: New generation of backup file; cataloged on success, discarded on failure; 50-byte fixed-length records //SYSIN DD * REPRO INFILE(FILEIN) OUTFILE(FILEOUT) // — Copies ALL records from FILEIN to FILEOUT with no filtering or transformation

Step 3 - STEP10R - Transaction Category Balance Record Layout Definition

Business Rules

Supporting Code

Rule 1 — Transaction Category Balance Record Layout Definition: ``` //SYMNAMES DD * TRANCAT-ACCT-ID,1,11,ZD TRANCAT-TYPE-CD,12,2,CH TRANCAT-CD,14,4,ZD TRAN-CAT-BAL,18,11,ZD ``` Rule 2 — Transaction Category Balance Report Sort Order: ``` SORT FIELDS=(TRANCAT-ACCT-ID,A,TRANCAT-TYPE-CD,A,TRANCAT-CD,A) ``` Rule 3 — Transaction Category Balance Report Output Record Structure: ``` OUTREC FIELDS=(TRANCAT-ACCT-ID,X, TRANCAT-TYPE-CD,X, TRANCAT-CD,X, TRAN-CAT-BAL,EDIT=(TTTTTTTTT.TT),9X) //SORTOUT DD DISP=(NEW,CATLG,DELETE), // DCB=(LRECL=40,RECFM=FB,BLKSIZE=0), // DSN=AWS.M2.CARDDEMO.TCATBALF.REPT ``` Rule 4 — Transaction Category Balance Amount Formatting: ``` TRAN-CAT-BAL,EDIT=(TTTTTTTTT.TT) ``` Rule 5 — Transaction Category Balance Report File Creation: ``` //SORTOUT DD DISP=(NEW,CATLG,DELETE), // UNIT=SYSDA, // DCB=(LRECL=40,RECFM=FB,BLKSIZE=0), // SPACE=(CYL,(1,1),RLSE), // DSN=AWS.M2.CARDDEMO.TCATBALF.REPT ```
