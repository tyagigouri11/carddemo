Summary

This JCL job (LOADPADB) executes an IMS Batch Message Processing (BMP) program named PAUDBLOD using the PSB PSBPAUTB to load payment authorization database records into an IMS database. The job reads two sequential input files — a root segment file and a child segment file — and populates the corresponding IMS database segments. ### Key Functionalities: - Reads root-level payment authorization records from the input sequential file (PAUTDB ROOT) and loads them as root IMS segments into the payment authorization IMS database. - Reads child-level payment authorization records from the input sequential file (PAUTDB CHILD) and loads them as child IMS segments linked to their respective root segments. - Utilizes the IMS BMP region (DFSRRC00) with PSB PSBPAUTB to manage database access and enforce IMS segment hierarchy during the load process. - References IMS PSB and DBD libraries to resolve the database structure definitions required for the load operation.
