Summary

This JCL job (IMSMQCMP) automates the full build pipeline for a CICS/IMS/MQ-integrated COBOL program (IMSMQPGM), performing CICS translation, COBOL compilation, and link-editing to produce a deployable load module. The job takes COBOL source code that integrates CICS transaction processing, IMS database access, and IBM MQ messaging, and produces a ready-to-execute load module stored in the CICS load library. ### Key Functionalities: - Translates the COBOL source program (IMSMQPGM) using the CICS preprocessor (DFHECP1$) with CICS, DLI (IMS), and COBOL3 options, converting CICS and IMS API calls into standard COBOL statements - Compiles the translated COBOL source using the IBM Enterprise COBOL compiler (IGYCRCTL) with options for non-dynamic linking, object code generation, re-entrant code, and cross-reference/map listings - Prepares the IMS entry point control card (ENTRY IMSMQPGM / NAME IMSMQPGM(R)) for inclusion during the link-edit step - Prepares the CICS language interface stub (DFHELII) link-edit control card to enable CICS runtime communication - Prepares the IBM MQ stub (CSQCSTUB from CSQSTUB) link-edit control card to enable MQ runtime communication - Link-edits all compiled object modules together with the CICS stub (DFHELII), MQ stub (CSQCSTUB), IMS entry point definition, and required system libraries to produce the final executable load module - Stores the final linked load module into the CICS load library (AWS.M2.CICSLOAD) as member IMSMQPGM, making it available for execution under CICS with IMS and MQ connectivity

Step 3 - COPYIMS - Conditional Execution of IMS Packaging Step

Business Rules

Supporting Code

**Rule 1 — Conditional Execution (Decision Gate):** ```jcl //COPYIMS EXEC PGM=IEBGENER,REGION=0M,COND=(4,LT) ``` > `COND=(4,LT)` — Skip this step if 4 is less than the return code of any prior step, i.e., skip if any prior step RC > 4. --- **Rule 2 — Define Executable Entry Point:** ```jcl //SYSUT1 DD * ENTRY IMSMQPGM ``` > Inline data directive: Sets IMSMQPGM as the execution entry point of the final load module. --- **Rule 3 — Name Load Module and Replace Existing Version:** ```jcl //SYSUT1 DD * NAME IMSMQPGM(R) ``` > Inline data directive: Names the load module IMSMQPGM. The `(R)` suffix enforces replacement of any existing version in the CICS load library. --- **Rule 4 — Create and Forward Instruction ** ```jcl //SYSUT2 DD DSN=&&COPYIMS,DISP=(NEW,PASS), // DCB=(LRECL=80,BLKSIZE=400,RECFM=FB), // UNIT=3390,SPACE=(400,(20,20)) //SYSIN DD DUMMY ``` > `DISP=(NEW,PASS)` — New temporary file created and passed forward to the LKED step. > `RECFM=FB, LRECL=80, BLKSIZE=400` — Fixed-block format, 80-byte records. > `SYSIN DD DUMMY` — No IEBGENER control statements; performs a straight copy of SYSUT1 to SYSUT2.

Step 4 - COPYLINK - Conditional Execution of CICS Interface Instruction Preparation

Business Rules

Supporting Code

**Rule 1 — Conditional Execution (Decision Rules):** ```jcl //COPYLINK EXEC PGM=IEBGENER,COND=(4,LT) ``` > `COND=(4,LT)` — If 4 is Less Than the return code of any prior step (i.e., any prior step RC > 4), skip this step entirely. --- **Rule 2 — CICS Language Interface Instruction File Creation and Forwarding (Action Rules):** ```jcl //SYSUT1 DD * INCLUDE SYSLIB(DFHELII) //SYSUT2 DD DSN=&&COPYLINK,DISP=(NEW,PASS), // DCB=(LRECL=80,BLKSIZE=400,RECFM=FB), // UNIT=3390,SPACE=(400,(20,20)) //SYSIN DD DUMMY ``` > `SYSUT1` — Inline input data containing the CICS Language Interface inclusion instruction `INCLUDE SYSLIB(DFHELII)`. > `SYSUT2 DSN=&&COPYLINK` — Output temporary file receiving the instruction. > `DISP=(NEW,PASS)` — File is newly created and passed forward to the link-edit step (LKED) for consumption. > `SYSIN DD DUMMY` — No additional IEBGENER processing directives; the copy operation is a straight file transfer.

Step 5 - COPYMQ - IBM MQ Interface Preparation Conditional Execution

Business Rules

Supporting Code

Rule 1 — Conditional Execution Decision: ```jcl //COPYMQ EXEC PGM=IEBGENER,COND=(4,LT) ``` > `COND=(4,LT)` — Skip this step if 4 is less than the return code of any prior step; i.e., execute only when all prior steps returned RC ≤ 4. --- Rule 2 — IBM MQ CICS Stub Include Directive Generation: ```jcl //SYSUT1 DD * INCLUDE CSQSTUB(CSQCSTUB) //SYSUT2 DD DSN=&&COPYMQ,DISP=(NEW,PASS), // DCB=(LRECL=80,BLKSIZE=400,RECFM=FB), // UNIT=3390,SPACE=(400,(20,20)) //SYSIN DD DUMMY ``` > `SYSUT1` — Inline input containing the IBM MQ stub include directive. > `INCLUDE CSQSTUB(CSQCSTUB)` — Instructs the link-edit step to bind the IBM MQ CICS Stub module into the final executable. > `&&COPYMQ, DISP=(NEW,PASS)` — Output is a new temporary file passed forward to the link-edit step and discarded after consumption. > `SYSIN DD DUMMY` — No IEBGENER transformation rules applied; content is copied as-is.

Business Rules
