Summary

This JCL job compiles a CICS DB2 program named CICSDB2P within the CardDemo application environment. It invokes a utility procedure (BLDCIDB2) to compile the COBOL source code, generate a Database Request Module (DBRM), and build a load module, binding it to the CARDDEMO plan on the DAZ1 DB2 subsystem. ### Key Functionalities: - Compiles the CICS DB2 COBOL program (CICSDB2P) from the source library AWS.M2.CARDDEMO.CBL using the BLDCIDB2 build procedure - Generates a Database Request Module (DBRM) and stores it in the AWS.M2.CARDDEMO.DBRMLIB library for DB2 plan binding - Links and stores the compiled load module into the AWS.M2.CARDDEMO.LOADLIB partitioned dataset for execution - Binds the compiled program to the CARDDEMO DB2 plan on subsystem DAZ1, enabling the program to execute DB2 SQL statements - References copybook members from AWS.M2.CARDDEMO.CPY and DB2 declarations from AWS.M2.CARDDEMO.DCL during compilation

Dataset Information (6)

Dataset/Table Name Type Usage
AWS.M2.CARDDEMO.CBL PDS Input - Source library containing the COBOL source code for member CICSDB2P to be compiled
AWS.M2.CARDDEMO.CPY PDS Input - Copybook library referenced during compilation to include shared COBOL copy members
AWS.M2.CARDDEMO.DCL PDS Input - DB2 DCLGEN declarations library providing SQL table declarations used during compilation

AWS.M2.CARDDEMO.DBRMLIB PDS Output - DBRM library where the Database Request Module generated during DB2 precompilation is stored for plan binding
AWS.M2.CARDDEMO.PROC.UTIL PDS Input - Procedure library containing the BLDCIDB2 catalogued procedure invoked to perform the CICS DB2 compile and bind process
