Summary

This JCL job compiles a CICS BMS (Basic Mapping Support) map named CICSMAP, assembles it into a load module, generates a DSECT (Data Section) copybook, and then activates the newly compiled map in the running CICS region (CICSAWSA) without requiring a restart. ### Key Functionalities: - Reads the BMS map source from the CARDDEMO BMS library (CICSMAP member) and copies it to a temporary dataset for processing. - Assembles the BMS map source using the ASMA90 assembler with MAP parameter to produce an object deck used for link-editing. - Link-edits the assembled map object into the CARDDEMO load library (CICSMAP member), making it available as an executable CICS map. - Assembles the BMS map source a second time with DSECT parameter to generate a COBOL copybook, storing the output in the CARDDEMO copy library (CICSMAP member) for use by application programs. - Displays the assembly listing on system output by copying the listing dataset, providing a visible record of the compilation results. - Issues a CICS CEMT command via SDSF to perform a NEWCOPY of the CICSMAP program in the active CICS region (CICSAWSA), immediately activating the newly compiled map without a CICS restart. - Cleans up the temporary dataset (&&TEMPM) at the end of the job to release allocated disk space.

High level flow diagram

Step 1 - PRINT - BMS Map Source Retrieval from CardDemo Library

Business Rules

Supporting Code

**Rule 1 — BMS Map Source Retrieval from CardDemo Library:** ```jcl //SYSUT1 DD DSN=&HLQ..CARDDEMO.BMS(CICSMAP), // DISP=SHR ``` > `DSN=&HLQ..CARDDEMO.BMS(CICSMAP)` identifies the CardDemo BMS source library and the CICSMAP member as the input source. `DISP=SHR` enforces shared (concurrent) access mode. --- **Rule 2 — Exact Copy of BMS Map Source to Temporary Staging Area:** ```jcl //SYSIN DD DUMMY //SYSUT1 DD DSN=&HLQ..CARDDEMO.BMS(CICSMAP), // DISP=SHR //SYSUT2 DD DSN=&&TEMPM,UNIT=3390,DISP=(,PASS), // DCB=(RECFM=FB,LRECL=80,BLKSIZE=400), // SPACE=(400,(50,50)) ``` > `SYSIN=DUMMY` means no control statements are provided, directing the utility to perform a straight copy with zero transformation. `DCB=(RECFM=FB,LRECL=80)` enforces the 80-character fixed-length record format on the output staging file. --- **Rule 3 — Temporary Staged File Availability for Downstream Assembly Steps:** ```jcl //SYSUT2 DD DSN=&&TEMPM,UNIT=3390,DISP=(,PASS), // DCB=(RECFM=FB,LRECL=80,BLKSIZE=400), // SPACE=(400,(50,50)) ``` > `DSN=&&TEMPM` defines the temporary staging file. `DISP=(,PASS)` instructs the system to keep the file alive and pass it forward to subsequent steps after the PRINT step completes, making it available for both the physical map assembly (MAP step) and the symbolic map assembly (DSECT step).

Step 2 - MAP - Physical BMS Screen Map Assembly from CardDemo BMS Source

Business Rules

Supporting Code

/* Rule 1 — Physical BMS Screen Map Assembly */ //MAP EXEC PGM=ASMA90,PARM='SYSPARM(MAP),DECK,NOLOAD' //SYSIN DD DSN=&&TEMPM,DISP=(OLD,PASS) //SYSPUNCH DD DSN=&&MAP,DISP=(,PASS),UNIT=3390, // DCB=(RECFM=FB,LRECL=80,BLKSIZE=400), // SPACE=(400,(50,50)) //SYSLIN DD DUMMY //*YSPRINT DD DSN=&HLQ..CARDDEMO.LST(CICSMAP),DISP=SHR ← intentionally commented out //SYSPRINT DD SYSOUT=* /* Rule 2 — Macro Library Search Order */ //SYSLIB DD DSN=OEM.CICSTS.V05R06M0.CICS.SDFHMAC,DISP=SHR // DD DSN=SYS1.MACLIB,DISP=SHR // DD DSN=CEE.SCEEMAC,DISP=SHR /* Rule 3 — Physical Map Object Deck Output Specification */ //SYSPUNCH DD DSN=&&MAP,DISP=(,PASS),UNIT=3390, // DCB=(RECFM=FB,LRECL=80,BLKSIZE=400), // SPACE=(400,(50,50)) //SYSLIN DD DUMMY //PARM='SYSPARM(MAP),DECK,NOLOAD'

Step 3 - LKED - Build Executable Screen Map Load Module

Business Rules

Supporting Code

**Rule 1 — Build Executable Screen Map Load Module:** ```jcl //LKED EXEC PGM=HEWL,PARM='LIST,LET,XREF' //SYSLMOD DD DSN=&HLQ..CARDDEMO.LOADLIB(CICSMAP),DISP=SHR //SYSLIN DD DSN=&&MAP,DISP=(OLD,DELETE) ``` **Rule 2 — Continue Link-Edit on Non-Severe Errors:** ```jcl //LKED EXEC PGM=HEWL,PARM='LIST,LET,XREF' ``` *(The `LET` parameter in PARM drives this rule — instructs the linkage editor to produce the load module even when non-severe errors are present)* **Rule 3 — Delete Physical Map Object Deck After Link-Edit:** ```jcl //SYSLIN DD DSN=&&MAP,DISP=(OLD,DELETE) ``` *(DISP=(OLD,DELETE) — the object deck is opened as an existing file and permanently deleted upon step completion)* **Rule 4 — Generate Link-Edit Audit Listing:** ```jcl //LKED EXEC PGM=HEWL,PARM='LIST,LET,XREF' //SYSPRINT DD SYSOUT=* ``` *(The `LIST` and `XREF` parameters in PARM drive this rule — detailed listing and cross-reference are written to SYSPRINT which routes to the job output log)*

Step 5 - DSECT - Symbolic Screen Map Copybook Generation

Business Rules

Supporting Code

**Rule 1 — Symbolic Screen Map Copybook Generation:** ```jcl //SYSPUNCH DD DSN=&HLQ..CARDDEMO.CPY(CICSMAP),DISP=OLD, // DCB=(RECFM=FB,LRECL=80,BLKSIZE=400), // SPACE=(400,(50,50)),UNIT=3390 //SYSIN DD DSN=&&TEMPM,DISP=(OLD,PASS) ``` **Rule 2 — Permanent Assembly Listing Storage:** ```jcl //*YSPRINT DD SYSOUT=* ← Commented out (listing NOT sent to job log) //SYSPRINT DD DSN=&HLQ..CARDDEMO.LST(CICSMAP),DISP=SHR ← Active: listing saved permanently ``` **Rule 3 — Macro Library Resolution Order:** ```jcl //SYSLIB DD DSN=OEM.CICSTS.V05R06M0.CICS.SDFHMAC,DISP=SHR ← 1st: CICS Macros (highest priority) // DD DSN=SYS1.MACLIB,DISP=SHR ← 2nd: IBM System Macros // DD DSN=CEE.SCEEMAC,DISP=SHR ← 3rd: Language Environment Macros ``` **Rule 4 — Symbolic Map Assembly Produces Copybook Only:** ```jcl //*SECT EXEC PGM=ASMA90,PARM='SYSPARM(DSECT),DECK' ← Commented: alternative without NOLOAD //SYSLIN DD DUMMY ← Active: load module output suppressed ``` **Rule 5 — Copybook Member Pre-existence Requirement:** ```jcl //SYSPUNCH DD DSN=&HLQ..CARDDEMO.CPY(CICSMAP),DISP=OLD, ← DISP=OLD: member must already exist // DCB=(RECFM=FB,LRECL=80,BLKSIZE=400), // SPACE=(400,(50,50)),UNIT=3390 ```

Step 6 - DISPLIST - Publish CICSMAP Assembly Listing to Job Output Log

Business Rules

Supporting Code

**Rule 1 — Publish CICSMAP Assembly Listing to Job Output Log:** ```jcl //DISPLIST EXEC PGM=IEBGENER,REGION=0M //SYSUT1 DD DSN=&HLQ..CARDDEMO.LST(CICSMAP),DISP=SHR <-- Input: CardDemo Listing Library (CICSMAP member) //SYSUT2 DD SYSOUT=* <-- Output: Job Output Log ``` **Rule 2 — Reproduce Assembly Listing Without Modification:** ```jcl //DISPLIST EXEC PGM=IEBGENER,REGION=0M //SYSIN DD DUMMY <-- No control statements = no filtering, selection, or transformation //SYSUT1 DD DSN=&HLQ..CARDDEMO.LST(CICSMAP),DISP=SHR <-- Source listing read as-is //SYSUT2 DD SYSOUT=* <-- Verbatim copy to job output log ```
